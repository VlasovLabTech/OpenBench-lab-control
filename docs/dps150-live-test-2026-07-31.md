## Hardware/API validation

All operations used the supported REST API:

- read complete identity, live measurements, setpoints, protections, display,
  metering, and six presets;
- apply stricter temporary protections with hardware readback;
- change setpoints while Output remains OFF;
- enable 0.5 V / 0.010 A, verify ON, then disable and verify OFF;
- change and verify brightness and volume;
- stop and restart Ah/Wh metering;
- save, apply, and restore preset 6 while preserving Output OFF;
- start sequence, pause it, verify no step advance while paused, resume, and
  complete naturally;
- complete a voltage sweep and a current sweep;
- verify every natural program completion forces Output OFF;
- set and clear instrument context through the generic settings API;
- capture a synchronized snapshot and a two-second CSV recording.

The global emergency-stop behavior and blocked output enable under a latched
safety state are covered by automated API tests rather than repeated on the
physical bench.
