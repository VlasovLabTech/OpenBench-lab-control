# Community code of conduct

OpenBench is a technical community built around respectful collaboration and
responsible laboratory automation.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and evidence rather than attacking people.
- Welcome different experience levels, languages, and backgrounds.
- Protect private laboratory data and disclose security issues confidentially.
- Treat hardware safety concerns seriously and avoid encouraging unsafe tests.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information without permission.
- Deliberately unsafe hardware instructions or attempts to bypass safety controls.
- Spam, sustained disruption, or knowingly misleading technical claims.

## Scope

This code applies to repository issues, pull requests, discussions, and other
spaces where someone is representing the OpenBench project.

## Reporting and enforcement

For an ordinary disagreement, ask a maintainer to review the relevant public
thread. For a confidential report, use the repository's GitHub private
vulnerability-reporting channel and state that the report concerns community
conduct. Do not include credentials, hardware identifiers, private captures, or
other unrelated sensitive data.

Maintainers may edit or remove contributions, lock conversations, issue a warning,
or temporarily or permanently restrict participation. Reports will be reviewed
in context and handled as privately as practical.
