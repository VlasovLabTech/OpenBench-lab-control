# Support

## Questions and setup help

Use GitHub Discussions for questions, setup help, hardware compatibility, and
ideas that are not yet actionable bug reports. Include the OpenBench version,
operating system, Python version, and instrument model when relevant.

Never post passwords, access tokens, serial numbers, private IP addresses,
operator comments, or unsanitized captures and logs.

## Bugs and feature requests

Use the repository's structured GitHub issue forms. Search existing issues first
and provide the smallest safe reproduction. Hardware reports should include the
model and firmware version but not a serial number.

## Security and safety

Follow [SECURITY.md](SECURITY.md) for vulnerabilities and safety-interlock issues.
Do not publish a procedure that could bypass a safety control. OpenBench is not a
certified safety system, and maintainers cannot validate a user's bench wiring or
load remotely.
