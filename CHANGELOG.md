## [0.1.0] - 2026-08-24

### Added

- Bilingual English and Russian web interface.
- Local instrument discovery, live measurements, snapshots, and CSV recording.
- Oscilloscope screenshots, measurements, waveform capture, and bounded exports.
- Signal-generator, power-supply, source/load, multimeter, and logic-analyzer
  integrations listed in the README hardware matrix.
- Commutation matrix, safety interlock, emergency stop, REST API, WebSocket API,
  and command-line client.
- Reproducible Windows setup, CI, dependency updates, package smoke testing, and
  publication auditing.
