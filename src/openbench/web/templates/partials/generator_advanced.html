Burst / trigger

Sends a fixed number of CH1 cycles after a CH2, external, or manual trigger. “Trigger once” is the manual one-shot action.

This is an active output action on CH1.
Modulation: ASK / FSK / PSK

CH1 is the carrier. ASK changes amplitude, FSK switches frequency, and PSK switches phase from an external or manual trigger. These are the modulation commands documented by the serial protocol.

This FY6200 did not answer ASK/FSK/PSK read-back commands during live testing, so OpenBench can send the documented commands but cannot confirm their state. AM/FM/PM depth and source controls are not exposed by the published protocol and are therefore not presented as working controls.
Sweep / VCO (CH1)

Timed sweep moves the selected CH1 parameter from Start to End during the selected duration. Start above End gives a reverse sweep. VCO instead maps an external 0–5 V signal on COUNTER IN to that range; its specified input rate is up to 1 kHz.

FY6200 exposes sweep/VCO writes but no read-back, so OpenBench reports this block as unverified. Round-trip sweep is not exposed by the published serial protocol and remains a front-panel function.
External counter

This measures a signal connected to the separate COUNTER IN connector; it does not internally measure CH1 or CH2. The manual specifies input above about 1.5 Vpp and no more than 20 Vpp. Frequency, count, period, both pulse widths, and duty cycle are saved to captures. Frequency and Count are separate instrument display modes, so OpenBench reads only the selected mode to avoid making the physical screen alternate continuously.
